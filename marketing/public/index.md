# NYX Chat — Zero-Knowledge Messenger

**Privacy-first, end-to-end encrypted messaging platform.**

## Overview

NYX Chat is a secure, zero-knowledge communication platform. All messages are encrypted end-to-end using the Double Ratchet protocol with post-quantum ML-KEM hybrid key exchange.

## Key Features

- **End-to-End Encryption** — Messages are encrypted on your device and can only be decrypted by the intended recipient
- **Zero-Knowledge Architecture** — The server never has access to message content, contact lists, or group metadata
- **Post-Quantum Security** — ML-KEM (Kyber) hybrid key exchange protects against future quantum attacks
- **Sealed Sender** — The server doesn't know who is messaging whom
- **Self-Destructing Messages** — View-once and ephemeral messages
- **Burner Chats** — Temporary conversations with no trace

## Get Started

1. Visit [app.nyx-app.my.id](https://app.nyx-app.my.id) to register
2. Generate your encryption keys (stored locally on your device)
3. Start messaging with end-to-end encryption
